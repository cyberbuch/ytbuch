# Changelog

Всички значими промени в ytbuch. Форматът следва [Keep a Changelog](https://keepachangelog.com/bg/1.1.0/),
а езикът е български. Пълната история е в `git log`.

## [Нерелизнато] — 2026-11-03

### Добавено
- **Приключвателни операции в края на месеца.** Карта `closing_map` в настройките
  на фирмата казва коя сметка/подсметка (префикс на номера) към коя сметка се
  приключва — при съвпадение печели най-дългият префикс (напр. `602 → 612`,
  останалите от `60 → 611`; по подразбиране без карта: група 60 → 611).
- API: `GET /v1/closing-operations/preview?year=&month=` (преглед без запис) и
  `POST /v1/closing-operations/run {year, month}` — записва балансирана статия
  `document_type='closing'`, номер `CLOSE-YYYY-MM`, дата последният ден на месеца.
  Затворен период или липса на салда → 422; повторно приключване за същия месец → 409.
- UI: таб **„Приключване“** в Настройки на фирмата (редактор на картата) и бутон
  **„Приключи“** на всеки отворен месец в „Счетоводни периоди“ с преглед на редовете.
- Страница `/changelog` на сайта (GitHub Pages) и този файл.

### Променено
- Приключвателните записи (`document_type='closing'`) вече могат да се изтриват
  от дневника — след изтриване месецът може да се приключи отново.
- Документация: `docs/api.md`, `docs/status.md`, `PLAN.md`, `TODO.md`,
  `user-docs/05-schetovodstvo.md`.

## [0.1.0] — 2026-10

Първа публична версия.

### Добавено
- Вход с JWT, еднократна парола за `superadmin` при първи старт, TOTP 2FA,
  сесии с версия (смяна на парола/имейл приключва старите токени).
- Многофирмена изолация по `company_id`, роли по фирми (администратор, счетоводител,
  фактурист), превключвател на активна фирма.
- Сметкоплан със seed от номенклатурите на НАП, контрагенти (уникалност по ЕИК/ДДС),
  стоки с КН8 класификация и авто-код.
- Фактури: чернова, пост, черно сторно, печат PDF/DOCX/ODT, UBL 2.1, дневник за ДДС
  и файлове за НАП, протокол по чл. 117 ЗДДС, митническа декларация.
- Ръчен запис в дневника с валидация Дт=Кт и отворен период; одитна следа.
- Банки (CSV/MT940), ДМА с амортизация, склад WAC/FIFO/LIFO, производство с рецепти,
  дивиденти, начални салда, счетоводни периоди (затваряне на месец).
- Справки: оборотна ведомост, главна книга, кореспонденции, баланс, ОПР, паричен
  поток; експорт PDF/XLSX/ODS. SAF-T XML експорт по BG_SAFT_Schema V1.0.1.
- Три Docker контейнера (YottaDB+Octo, Rust API на :8092, Next.js на :3020) и сайт
  на GitHub Pages (ytbuch.cfd).
